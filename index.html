WCAG 2.2 Level AA Testing & Accessibility Checklist

This application has been engineered to adhere strictly to Web Content Accessibility Guidelines (WCAG) 2.2 Level AA standard specifications:

  • 2.1.1
    Keyboard Operability (No Mouse Required) Full canvas crosshair navigation using Arrow Keys with Enter/Space tag placement and Delete capabilities.
  • 2.4.7
    Focus Visible & Ring Contrast Custom 3px high-contrast focus ring (#0284c7) applied across all interactive controls.
  • 1.4.1
    Use of Color (Dual Shape + Color Coding) Markers and tools rely on dual encoding: Stomata use red circles with letter 'S'; regular cells use blue squares with letter 'C'.
  • 4.1.2
    Name, Role, Value & Live Region Feedback All updates to counts, mode toggles, and calculation verifications are announced dynamically via aria-live="polite" regions.
  • 1.4.3
    Contrast (Minimum 4.5:1) Strict adherence to high contrast color pairings for all body text, UI buttons, inputs, and canvas marker badges.
  • 1.3.1
    Non-Visual Alternative Inputs Provides collapsible numeric inputs for manual direct count entry without requiring canvas click interactions.
